  • Episode 1 · Blender 5.1 · Python

    Watercolour pumpkin

    Four prompts, one hour, zero lines of code typed by hand: an AI wrote the Python that models, carves, lights and shades this jack-o'-lantern. Run the script and the whole scene builds itself — candle inside, lavender shadows, painterly compositor and a looping turntable. Everything is tweakable: the settings at the top of the file control the ribs, the squash, the candle and the brush size.

    Heads-up: the script clears the current scene before it builds, so run it in a fresh file or save your work first. It opens in FAST mode — switch QUALITY to "FULL" for the final render.

How to run a script in Blender

  1. 1Download the .py file from this page and remember where it landed.
  2. 2In Blender, open the Scripting workspace in the top bar.
  3. 3Press Open in the text editor and pick the downloaded file.
  4. 4Press Run Script — or hover over the editor and hit Alt + P.

The scripts are plain text — open one in any editor if you want to read it before running it. Use them freely in your own work, commercial or not.
